FAQs

How do I register?

Choose an available event and click Register. The seat count updates automatically.

Can I cancel my registration?

Yes. Use the Cancel button on the event card to free up one seat.

What happens when an event is full?

The Register button becomes disabled when there are no seats left.

Who can add events?

Use the Add New Event form to add school activities with a title, category, date, and seats.

About Us

A simple place for students to find what is happening next.

EventHub is a student event registration dashboard designed for school life. It helps learners discover upcoming activities, check dates and locations, register for seats, and see when an event is already full.

The platform keeps the experience clear for everyone: students can browse quickly, organizers can add new events without confusion, and teachers can see registration numbers at a glance. The design is responsive, so the same information works well on phones, tablets, and desktop screens.
